# Random Password Generator

**Автор:** [Щевцова Анастасия Сергеевна]

**Описание:**
Приложение с графическим интерфейсом (Tkinter) для генерации надёжных случайных паролей.

**Технологии:**
- Python 3.x
- Tkinter (GUI)
- JSON (сохранение данных)
- Git (контроль версий)

**Как запустить:**
1. Установите Python.
2. Клонируйте репозиторий.
3. Запустите: `python main.py`

**Примеры использования:**
Позволяет настроить:
- длину пароля (от 1 до 50) при помощи ползунка;
- использование цифр, букв (верхний+нижний регистр) и специальных символов;
- генерировать пароль одним нажатием;
- копировать пароль в буфер обмена;
- сохранять историю всех сгенерированных паролей в JSON-файл;
- просматривать историю (последние 20 записей) в таблице;
- очищать историю.
